# 07. QE 콘솔

- 마감: 미정
- 단계: phase-2
- 관련 설계: 설계서 11장(QE 흐름)
- 배경: 스펙 06

## 배경

지금까지의 결과는 스크립트 출력과 리포트 md로만 남아, 감지부터 격리까지의 흐름이 한눈에 보이지 않는다. 또 불량은 팹 아웃과 분류가 끝난 뒤에야 알 수 있다(사후 집계). 화면이 이 시간 차이를 숨기면 실제보다 빨리 아는 것처럼 보인다.

## 목표

가상 팹의 40일을 하루씩 재생하며, 그날까지 알 수 있는 정보만으로 감시, 조사, 격리 결정을 보여 주는 콘솔을 만든다. QE의 결정을 기록하고, 정답과 비교해 결정의 결과를 보여 준다.

## 범위

- 날짜 슬라이더: d일차를 고르면, d일차까지 팹 아웃되고 판정이 나온 웨이퍼만으로 관리도와 챔버 감시를 그린다.
- 알림 목록: 각 알림이 실제로 알 수 있었던 날과, 원인 챔버를 처음 지난 날의 차이를 함께 보인다.
- 조사 보기: 스펙 06 에이전트의 추적 기록(도구 호출 순서, 결과, 인용)과 8D 보고서 초안.
- 결정: 보류 목록을 승인, 기각, 수정할 수 있고 결정은 파일로 쌓인다.
- 사후 비교: 결정한 보류 범위를 정답과 비교해 놓친 로트와 초과 보류를 보여 준다.
- API 키 없이도 돈다. 미리 기록한 에이전트 실행을 읽는다.

## 비범위

- 로그인, 배포
- 실제 알림 발송 (이메일, 메신저)
- 에이전트를 콘솔에서 새로 실행하는 기능 (있으면 좋음으로 둔다)
