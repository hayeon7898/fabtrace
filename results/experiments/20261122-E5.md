# E5. 개선 방법의 격리 여유 시간 재검토

## 가설

1. A를 켜면 24시간보다 짧은 여유 시간으로도 lot recall 1.0을 유지할 수 있다.
2. 여유 시간을 줄이면 lot precision이 오른다.

## 조건

| 항목 | 값 |
| --- | --- |
| 시나리오 | S1 (`configs/scenarios/s1.yaml`) |
| 시드 | 개발 seed 42만 (평가 시드 100~109는 쓰지 않음) |
| 방법 | `exposure+chamber` |
| 관련 커밋 | `98cf0e04398ce7708123113eec421b472c2b2945` |
| 데이터 확인 | `check_data.py` 전 항목 OK (실제 예측). <br> 합성 예측은 WM-811K 맵을 쓰지 않음 |
| 노트북 또는 스크립트 | `scripts/run_e5.py` |
| 분류기 | `cnn_v1` (실제 예측), 합성 예측은 분류 오차 없음 |
| 관련 이슈 | #41 |

## 방법

- 실제 예측: seed 42 가상 팹과 `cnn_v1` 예측에 여유 0, 6, 12, 18, 24시간을 적용한다.
- 합성 예측: seed 42 이력에 맵 배정만 시드 0~49로 바꾼다. 평상시 패턴은 WM-811K 클래스 비율, 영향 웨이퍼는 0.4 확률로 Edge-Ring이고, 예측은 배정된 패턴 그대로다.
- `exposure+chamber`로 센다. 합성 예측에서 공장 전체 감시가 놓치면 여유 시간과 무관하게 recall이 0이 되기 때문이다. seed 42 실제 예측은 `exposure`와 결과가 같다.
- 판단 기준(실행 전에 #41에 적음): 실제 예측 lot recall 1.0, 합성 lot recall 평균 0.98 이상, 최솟값 0.9 이상인 값 중 가장 짧은 값. 24시간보다 짧지 않으면 24시간을 유지한다.

## 결과

- 합성 예측 감지 50/50, 
- 원인 특정 50/50.

| 여유 시간 | 실제 recall | 실제 precision | 합성 recall 평균 | 합성 recall 최소 | 합성 precision 평균 | 기준 통과 |
| --- | --- | --- | --- | --- | --- | --- |
| 0h | 1.000 | 1.000 | 0.988 | 0.737 | 0.991 | X |
| 6h | 1.000 | 0.950 | 0.988 | 0.737 | 0.947 | X |
| 12h | 1.000 | 0.950 | 0.988 | 0.737 | 0.947 | X |
| 18h | 1.000 | 0.905 | 0.991 | 0.789 | 0.908 | X |
| 24h | 1.000 | 0.905 | 0.996 | 0.842 | 0.908 | X |


| 가설 | 판정 |
| --- | --- |
| 1. 24시간보다 짧은 여유로 recall 1.0 유지 | 기각. 실제 예측은 0시간부터 recall 1.0이지만, 합성 예측 최솟값이 모든 여유 시간에서 0.9 미만(0.737~0.842)이라 기준을 통과한 값이 없다 |
| 2. 여유를 줄이면 precision이 오른다 | 지지. 합성 precision 평균이 24시간 0.908에서 0시간 0.991로 오른다. 실제 예측도 0.905에서 1.000으로 오른다 |

## 해석

- 판단 기준을 통과한 여유 시간이 없어 24시간을 유지한다. 24시간도 합성 recall 최솟값 0.842로 기준(0.9)에 못 미친다.
- recall이 낮았던 4개(draw 10, 12, 23, 44)는 모두 노출 기간의 경계 날(12, 13일차 또는 18일차)에 지나간 로트를 놓쳤다. 
  - 그 로트들은 영향 웨이퍼 8~9장 중 Edge-Ring이 된 것이 0~3장뿐이라(기대 약 3.4장), 그날의 원인 챔버 불량률이 관리한계에 못 미쳤다. 
  - 놓친 날이 노출 기간 끝에서 하루 이상 떨어져 있어 여유 24시간으로도 일부만 덮인다. 
  - 방법의 오류가 아니라 경계 날 신호 부족에 따른 한계다.
- 여유 24시간의 precision은 실제 0.905, 합성 0.908로, #33 사전 탐색(0.7대, 평상시 불량률 5% 고정, 다른 이력 시드)보다 높다. E4 가설 3이 기각될 위험은 예상보다 작다.
- 합성 예측은 seed 42 이력 하나에서 맵 배정만 바꾼 것이라, 로트 흐름이 다른 이력에서의 안정성은 보여주지 못한다. E4의 여유 시간별 표로 확인한다.


## 다음 조치

#### 1. 기본 여유 시간은 24시간을 유지한다.
 코드는 바꾸지 않고, E4는 24시간 기준으로 가설을 판정한다.
#### 2. 경계 날 신호 부족은 현재 방법의 한계로 남기고 E4를 진행한다. 
구간 경계에 붙은 날을 낮은 한계로 포함하는 규칙은 E4 뒤 새 평가 시드로 검증할 후속 과제로 둔다.
